## Why

- Four lower-input-level windows [300k,1100k) have candidate DI RMS roughly 0.00054–0.00078, around 2.0–2.1% **per-window gain-fitted** residual, with gain ~0.30906.
- Two later windows [1100k,1500k) have candidate DI RMS ~0.188–0.394, residual 0.04–0.066%, and gain ~0.31.
- Early four windows contribute **99.7483% of the sum of individually gain-fitted squared residuals** and about 17.21% of the Manager WAV energy. This does *not* describe residual with one global fit.
- Across all six 200k windows, the best **integer** lag in [-4,+4] is zero; adding constant DC offset barely improves the early residual. Prewarm ON/OFF are bitwise identical inside this window (Stage104).

These observations **do not** identify the source of the error or prove vendor NAM/fitter parity. In particular, the 48-kHz input used by open NAM Core was generated by an open SonicMaster *candidate resampler*, not the as-yet unverified vendor preprocessor. The original exact model bytes inside Manager and `outputFile.wav`'s native-buffer provenance remain unverified.

## What Stage106 calculates

1. Validate the Stage105 private JSON schema and provenance flags; require exactly six contiguous 200000-frame coarse bins and sixty contiguous 20000-frame fine bins, finite nonnegative RMS values, internally consistent normalized RMS, and the mathematical least-squares coarse/fine residual-energy inequality. Refuse overwriting prior Stage106 result.
2. Report **per-group RMS energy** of the candidate DI, reference WAV, and gain-fitted residual for early four versus late two coarse windows. Compute early residual-energy and reference-energy fractions using **equal-length window RMS squared** (not arithmetic averages of percentage errors).
3. Report the ratio of late to early candidate-DI RMS and residual RMS in units of one PCM16 LSB (1/32768), explicitly *not* attributing that residual to PCM16 quantization.
4. On all valid 20k bins, compute a **descriptive Spearman rank correlation** between log10(candidate DI RMS) and log10(relative residual). This is a relationship across one scripted stimulus, **not** a causal model or statistical population inference.
5. Report the largest *adjacent-bin reduction* of relative residual and five bins with largest **absolute residual squared energy**, contrasting these with Stage105's five largest *relative* residual bins. No claim of a true signal discontinuity is made from bin boundaries.

No extra dependencies: Python 3.11+ standard library. The report is confined to the ignored existing Stage102 private run folder as `stage106_metrics_audit_private.json`. SHA256 of the source Stage105 report is recorded for local provenance; the script **does not independently revalidate original upstream input/output sample hashes** — those were checked by Stage105.
